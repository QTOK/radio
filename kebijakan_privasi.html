Kebijakan Privasi

Terakhir diperbarui: 2025

Selamat datang di Radio Downface (https://www.radio.downface.org). Kami menghargai privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana kami mengelola data pengguna saat menggunakan layanan radio online kami.

1. Informasi yang Kami Kumpulkan

Radio Downface berkomitmen untuk menjaga privasi pengguna. Kami TIDAK mengumpulkan informasi pribadi seperti nama, alamat, nomor telepon, atau data sensitif lainnya.

1.1. Informasi Wilayah

Saat Anda memasukkan daerah/wilayah untuk mencari radio aktif:

  • Informasi wilayah hanya diproses untuk menampilkan daftar siaran radio yang sesuai.
  • Kami TIDAK menyimpan informasi lokasi Anda di server.
  • Kami TIDAK melakukan pelacakan lokasi secara otomatis.

1.2. Data Teknis

Kami dapat mengumpulkan data non-pribadi untuk keperluan analitik seperti:

  • Jenis browser atau perangkat
  • Halaman yang dikunjungi
  • Waktu akses

Data ini sepenuhnya anonim dan digunakan hanya untuk meningkatkan layanan.

2. Penggunaan Informasi

Informasi yang diproses digunakan semata-mata untuk:

  • Menampilkan daftar radio sesuai daerah
  • Memastikan layanan radio berjalan dengan baik
  • Memahami penggunaan aplikasi secara umum (analitik non-pribadi)

3. Streaming Radio

Radio Downface hanya menyediakan tautan streaming dari sumber stasiun radio yang tersedia di publik. Kami tidak menyimpan audio, rekaman, atau materi siaran apa pun.

4. Keamanan Data

Kami menerapkan langkah-langkah keamanan untuk melindungi penggunaan situs, termasuk:

  • Penggunaan server yang aman
  • Tanpa penyimpanan data pribadi pengguna
  • Tanpa pelacakan otomatis lokasi pengguna

5. Cookie dan Teknologi Pelacak

Website ini dapat menggunakan cookie untuk meningkatkan pengalaman pengguna, seperti penyimpanan preferensi tampilan. Anda dapat menonaktifkan cookie melalui pengaturan browser jika diinginkan.

6. Layanan Pihak Ketiga

Website ini dapat menampilkan iklan atau analitik pihak ketiga. Pihak tersebut mungkin mengumpulkan data non-pribadi seperti:

  • Alamat IP
  • Interaksi dalam situs

Data ini tidak digunakan untuk mengidentifikasi Anda secara pribadi.

7. Hak Pengguna

Anda berhak untuk:

  • Mengetahui bagaimana data digunakan
  • Menolak penggunaan cookie
  • Menghubungi admin jika ada pertanyaan mengenai privasi

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan ini sewaktu-waktu. Setiap perubahan akan dipublikasikan di halaman ini.
